Mity Reel Publisher — Caption Input Fix

This update changes caption entry to use a sentinel line instead of an empty line. This lets you paste multi-paragraph captions with blank lines.

Install from the project root:

  unzip -o ~/Downloads/Mity-Reel-Publisher-caption-input-fix.zip -d .
  instagram-dm/.venv/bin/python -m py_compile instagram-upload/instagram_reel_uploader.py

Usage:
  Paste the full caption, including blank lines, then type END on a line by itself and press Enter.

The script will then continue to inventory and safety confirmations.
